# Retail Sales & Business Performance Analysis using SQL

## Project Overview
This project analyses retail sales data using MySQL to understand product performance, customer orders, revenue, and regional sales.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
- Customers — customer details
- Products — product names, categories, and prices
- Orders — order dates, regions, and order statuses
- Order_Items — quantities, prices, and discounts

## SQL Concepts Used
- SELECT and WHERE
- ORDER BY and LIMIT
- GROUP BY and HAVING
- Aggregate functions: COUNT, SUM, AVG, MIN, MAX
- JOIN operations
- Subqueries
- CASE statements
- Revenue and profit calculations

## Key Analysis
- Product sales and pricing analysis
- Order status analysis
- Revenue and estimated profit calculations
- Regional sales comparisons
- Customer order analysis

## Dataset
Practice dataset containing sample records created for SQL learning and analysis.

## Disclaimer
This is an educational portfolio project using sample data, not actual company sales data.
